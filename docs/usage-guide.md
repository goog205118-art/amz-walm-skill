# 电商 Skill 工作台使用逻辑文档

## 1. 打开工作台

内部成员可以直接打开部署后的 Vercel 地址，也可以在本地直接打开 `index.html` 试用。

页面主要分为三块，右侧说明区可以按需展开或收起：

- 左侧：技能筛选、技能库、会话列表
- 中间：当前技能对话区
- 右侧：技能说明、核心能力、执行流程、路由状态、工作区统计

## 2. 配置模型

点击顶部“设置”打开模型与接口设置页，填写：

- 模型：例如 `gpt-4.1-mini`
- 模型池：每行一个可选模型，保存后可在下拉框选择
- API 密钥：使用者自己的大模型 API 密钥
- 接口地址：默认兼容 OpenAI Chat Completions

点击“保存设置”后，配置会保存到当前浏览器缓存。刷新页面后仍会保留。

如果没有填写 API 密钥，系统会进入“演示模式”，可以完整演示技能路由和结构化回复流程，但不会真正调用大模型。

## 3. 选择或搜索技能

在左侧可以通过三种方式找到技能。会话数量较多时，会话列表会在自己的区域内滚动，不影响中间对话区点击。

- 输入关键词搜索，例如“利润”“竞品”“Listing”“Walmart”
- 点击分类筛选，例如策略、财务、调研、内容、营销
- 点击平台筛选，例如 Amazon、Walmart、Shopify

点击某个技能后，中间对话区会切换到该技能，右侧会展示技能摘要、能力和执行流程。

## 4. 新建和使用会话

点击“新建会话”会基于当前技能创建一个新会话。

在输入框里写清楚任务背景，例如：

```text
我们有一款 Amazon 家居收纳产品，售价 29.99 美元，毛利不稳定，想判断是否需要调价。
```

点击“发送”后，系统会先根据关键词路由到最合适的技能，再让大模型按该技能的要求生成回答。右侧“路由状态”会显示本次命中的原因。

## 5. 导入 Skill 文件

如果有新的 `SKILL.md` 或 `.txt` 技能文件，点击“导入 Skill”选择文件即可。

导入后，系统会自动提取：

- 技能标题
- 摘要
- 平台
- 分类
- 核心能力
- 执行流程
- 输出要求

导入的技能会保存到浏览器缓存，刷新后不会丢失。

## 6. 导出和导入工作区

点击“导出工作区”可以备份当前浏览器里的完整工作区，包括：

- 模型和接口配置
- 会话记录
- 导入的自定义技能
- 当前筛选和路由状态

换电脑、换浏览器或清理缓存前，建议先导出工作区。需要恢复时点击“导入工作区”选择导出的 JSON 文件。

## 7. 部署和安全边界

当前项目是轻量静态前端，适合直接部署到 Vercel。

注意事项：

- API 密钥保存在使用者自己的浏览器缓存中
- 不建议公开给外部用户使用
- 若后续扩大使用范围，建议增加后端 API 代理，避免前端直接暴露密钥
- 浏览器缓存被清理后，本地会话和导入技能会丢失，因此重要内容需要定期导出工作区
